# Idle Island Planning

## 바로 플레이

**[웹에서 Idle Island Planning 플레이하기](https://dum-sooez1111.github.io/city/)**

밝은 2D 탑다운 섬을 개발하는 브라우저용 방치형 도시 건설 게임입니다.

## 플레이

`index.html`을 브라우저에서 열면 바로 실행됩니다. 별도의 빌드 과정이나 서버가 필요하지 않습니다.

- 바나나 농장, 벌목장, 광산, 항구 건설 및 업그레이드
- 건물을 눌러 생산 수익 수확
- 실시간 자동 수익과 움직이는 트럭·화물선
- 자원 수출, 연구, 섬 레벨 및 미션
- 게임 시작 시 10분 생산 수익 부스트
- 시설 15레벨마다 변화하는 5단계 트럭 외형과 누적 생산 수익·속도 50% 보너스
- 시설 15레벨마다 완벽 배송 확률 1% 증가 및 완벽 배송 수익 2배
- 코인으로 최대 10레벨까지 올리는 도로·차량 속도
- 잠금 해제, 생산, 업그레이드를 설명하는 게임 내 가이드북
- 브라우저 로컬 저장
- PC와 모바일 반응형 UI
- PC 좌클릭 드래그 및 모바일 터치 드래그 지도 이동
- 잠금 지역을 피하는 트럭 경로와 크레인 컨테이너 선적·화물선 출항
- 화물 대기량에 따른 다중 트럭 배차, 트럭당 화물 1개 운송
- 각 생산 시설 15레벨마다 해당 화물 전용 트럭 1대 자동 추가
- 트럭 상차 시간과 크레인 선박 선적 시간을 각각 줄이는 무역 업그레이드
- 수익 목표 달성 시 섬 레벨 상승, 다음 레벨 목표 금액 3배 증가
- 건물·차량·선박·크레인을 포함한 전체 탑다운 시점 디자인
- 광고나 영상 시청 없이 모든 기능 이용 가능

## 구조

- `index.html` — 게임 화면과 HUD
- `styles.css` — 반응형 인터페이스와 애니메이션
- `game.js` — Canvas 지도, 게임 루프 및 저장 시스템
